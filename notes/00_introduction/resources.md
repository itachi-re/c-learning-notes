# Chapter 00 — References & Further Reading

Only authoritative, primary, or widely-recognized sources are listed here — no random blog posts or SEO-optimized tutorial sites.

## Primary / Historical Sources

- Kernighan, B. W., & Ritchie, D. M. — ***The C Programming Language*** (2nd Edition). The original reference text for the language, written by its creators. Dense but foundational; worth owning a copy long-term.
- Ritchie, D. M. — *"The Development of the C Language"* (1993), presented at the ACM History of Programming Languages conference. Ritchie's own account of C's origins. Available via the ACM Digital Library and archived on Ritchie's Bell Labs homepage.
- Ritchie, D. M., Thompson, K. — Early UNIX papers from Bell Labs, archived at bell-labs.com and various university computer science history archives.

## Language Standards

- **ISO/IEC 9899** — the formal C standard. The final C11 and C17 drafts are freely available as PDFs from the official ISO working group (WG14) website. C23 documentation is also published through WG14.
- **cppreference.com/w/c** — an excellent, continuously updated, community-maintained reference for the C standard library and language features across all standard versions. Not official, but exceptionally accurate and widely used by professional C developers.

## Guides

- Beej's Guide to C Programming — a free, widely respected, plain-language guide covering the language from fundamentals through more advanced topics. Excellent as a secondary explanation alongside this course.
- The GNU GCC Manual (`gcc.gnu.org/onlinedocs`) — official documentation for GCC, including the full list of warning flags you'll start using in Chapter 01.
- The Clang documentation (`clang.llvm.org/docs`) — official documentation for the Clang/LLVM compiler, the other major C compiler you'll use throughout this course.

## On UNIX History Specifically

- Salus, P. H. — ***A Quarter Century of UNIX***. A well-regarded history of UNIX's development and spread.
- The Unix Heritage Society (tuhs.org) — an archive of historical UNIX source code and documentation, including early C compilers.
