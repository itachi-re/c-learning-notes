# resources.md

## Official Compiler Documentation

- **GNU GCC Manual** (`gcc.gnu.org/onlinedocs`) — the authoritative reference for every GCC flag, including the full, exhaustive list of warnings enabled or excluded by `-Wall` and `-Wextra` specifically.
- **Clang documentation** (`clang.llvm.org/docs`) — official documentation for the Clang/LLVM compiler, including its own warning flag reference.

## Language Reference

- **cppreference.com/w/c** — a continuously updated, community-maintained reference for C language features and the standard library, covering every standard version from C89 through C23.
- **ISO/IEC 9899 (WG14)** — the formal C standard documents. Final drafts of C11, C17, and C23 are freely available through the WG14 committee's site.

## Guides

- **Beej's Guide to C Programming** — a clear, thorough, freely available guide covering the language from setup through advanced topics, written in a plain, direct style.
- **GNU Make Manual** (`gnu.org/software/make/manual`) — the official reference for Makefile syntax, previewed briefly in this chapter and covered fully in Chapter 21.

## Debugging & Analysis Tools

- **GDB documentation** (`sourceware.org/gdb/documentation`) — official manual for the GNU Debugger, used starting in Chapter 20.
- **Valgrind documentation** (`valgrind.org/docs`) — official manual for Valgrind's memory-checking tools, used starting in Chapter 16.
